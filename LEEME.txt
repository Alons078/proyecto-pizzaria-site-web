REY PIZZARIA — prototipo

Cómo correrlo:
1. Necesitas Python instalado, y Flask (pip install flask --break-system-packages
   si no lo tienes).
2. Abre una terminal DENTRO de esta carpeta (rey-pizzaria).
3. Ejecuta: python3 app.py
4. En el navegador abre:
   - http://127.0.0.1:5000/        -> vista del cliente (blog)
   - http://127.0.0.1:5000/admin   -> panel del administrador

Estructura que debe quedar (no muevas archivos sueltos):
  rey-pizzaria/
  ├── app.py
  ├── data.json
  ├── templates/  (cliente.html, admin.html)
  └── static/     (style.css, client.js, admin.js, images/logo.jpg)
